## Goal

Fix 3 P2 review findings from HLF integration: negative query param validation, unhandled import() rejections, and gateway connection code duplication.

## Research Findings

- `fabric.routes.ts:52-53` — `parseInt("-5") || 0` = `-5`, PostgreSQL `LIMIT -5` errors
- `index.ts:215,237,253,276` — `import().then(...)` without outer `.catch()` silently swallows import failures
- `fabricAnchor.service.ts` is 416 lines; `submitToFabric()` (283-347) and `queryFabric()` (352-398) share ~25 lines of identical gateway connection setup
- Existing push notification dynamic import at `index.ts:206` also lacks outer `.catch()` (pre-existing, not in scope)

## Implementation Steps

### Step 1: Fix negative limit/offset → `backend/src/api/routes/fabric.routes.ts`
- Line 52: `Math.min(parseInt(...) || 50, 100)` → `Math.min(Math.max(1, parseInt(...) || 50), 100)`
- Line 53: `parseInt(...) || 0` → `Math.max(0, parseInt(...) || 0)`

### Step 2: Add outer `.catch()` to HLF import chains → `backend/src/index.ts`
- 4 locations (lines 215, 237, 253, 276): add `.catch(err => logger.error(...))` to `import().then(...)`
- Pattern: `import('./services/fabricAnchor.service').then(({ anchorRecord }) => { ... }).catch(err => logger.error('HLF import failed', { error: err }))`

### Step 3: Extract `connectToFabric()` helper → `backend/src/services/fabricAnchor.service.ts`
- Extract shared gateway setup (import SDK, read certs, create client, connect) into:
  ```typescript
  async function connectToFabric(): Promise<{ gateway: any; client: any; contract: any }>
  ```
- Refactor `submitToFabric()` and `queryFabric()` to call `connectToFabric()`
- Target: ~380 lines (from 416)
